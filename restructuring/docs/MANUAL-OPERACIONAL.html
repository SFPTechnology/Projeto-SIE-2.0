01 · Primeira execução

São necessários Python 3.11 ou superior e dois terminais PowerShell, dentro da cópia local do repositório.

Terminal 1 — API

cd restructuring\apps\api
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"
python -m pytest -q
python -m uvicorn sie_api.main:app --reload

Terminal 2 — interface

cd restructuring\apps\web
py -3.11 -m http.server 5173

Abra http://127.0.0.1:5173. A documentação da API estará em http://127.0.0.1:8000/docs.

03 · Preenchimento passo a passo

CampoSignificado
Corrente (A)Ib: corrente de projeto do circuito.
Comprimento (m)Distância elétrica de ida. O cálculo monofásico resistivo considera ida e retorno.
Tensão (V)Tensão nominal do circuito.
Resistência (Ω/km)Resistência aplicável à seção e à condição térmica estudada.

A tabela de condutores da interface contém valores demonstrativos embutidos no JavaScript. Não a interprete como tabela normativa automaticamente verificada.

Após preencher, selecione Executar análise. Nenhum checkbox pode autorizar uso profissional: a aprovação normativa é bloqueada até existir uma revisão independente no servidor.

04 · Entendendo os resultados

Condutor: menor seção demonstrativa cuja capacidade corrigida alcança Ib. Disjuntor: menor valor comercial do catálogo embutido que atende ao critério preliminar Ib ≤ In ≤ Iz. Isso não encerra a verificação de sobrecarga/curto-circuito.

Queda de tensão: modelo resistivo monofásico ΔV = 2 × L(km) × I × R; a aplicação não incorpora reatância, fator de potência nem topologia trifásica nesse cálculo.

Gate: status PENDENTE indica que há cálculo demonstrativo, mas não autorização normativa; BLOQUEADO indica ausência/inconsistência grave.

05 · Padrão de entrada EDP

O endpoint POST /api/v1/edp/enquadrar oferece categoria candidata por modalidade e corrente, a partir de um catálogo documentado EDP São Paulo v09. Requisitos de carga, modalidade, medição e condições adicionais precisam de análise própria.

O retorno candidato_para_estudo=true não é aprovação. O campo liberado_para_padrao_entrada permanece false nesta versão.

06 · Testes e problemas comuns

Execute python -m pytest -q no terminal da API. Para conferir o funcionamento da interface, abra a página local e realize um circuito de demonstração.

07 · Escopo, segurança e próximos módulos

Este incremento destina-se a teste local controlado. A API não possui ainda autenticação de produção, persistência exposta com controle de acesso ou aprovação normativa certificada. O SQLite local versionado é um componente de infraestrutura em teste, ainda não integrado ao fluxo da interface.

Faltam motores normativos completos, quadros de carga, diagramas, planta, memoriais, relatórios finais e QA independente. Antes de uso profissional, exija fonte técnica primária, edição, tabelas reproduzíveis, cálculos de referência e revisão por responsável habilitado.

03 · PERSISTÊNCIA LOCAL

Salvar e reabrir análises

Recurso experimental, somente para ambiente local. A API exige token de desenvolvimento e mantém a aprovação normativa desabilitada.

Salva a última análise executada com sucesso. Ao reabrir, confira os campos e execute novamente o cálculo.

Armazenamento desabilitado até configurar a API local e o token.

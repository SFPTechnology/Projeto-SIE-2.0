## 🔥 DIFERENCIAIS ÚNICOS

### 1. Prompts de IA Elite
Cada imagem com prompt de 500+ palavras incluindo:
- Estilo visual específico
- Composição detalhada (ângulo, framing)
- Iluminação (natural/artificial, direção)
- **Paleta exata com HEX codes**
- Mood e atmosfera
- Parâmetros técnicos (Midjourney/DALL-E/SD)
- Negative prompts robustos

**Exemplo:**
```
Isometric 3D illustration of business growth, ascending glass staircase
(5 steps, each 1m × 1m), data points floating (23%, 45%, 67%, 89%),
abstract figure climbing (1.8m tall, #003B5C navy blue), geometric
shapes surrounding (#00A86B green 40% opacity), gradient background
(#FFFFFF to #F8F8F8), drop shadows 20% opacity 15px blur, ultra-modern
corporate aesthetic, --ar 16:9 --stylize 300 --no text, faces --v 6.0
```

### 2. Enumeração Automática
Todo elemento visual recebe ID único:
- Gráfico 7
- Tabela 7.1
- Imagem 7.2

### 3. Fontes Rastreáveis
Formato APA completo:
```
Fonte: IDC Brasil. "Mercado de IA 2024-2027". Março 2024.
https://idc.com/br/reports/ai-market. Acesso em: 10 dez 2024.
```

### 4. Grid System Preciso
- 12 colunas × 8 linhas
- Posicionamento: "Colunas 2-9, Linhas 3-6"
- Dimensões: "14cm × 8cm"

## 📖 WORKFLOW DE USO

### Fase 1: Análise (20%)
1. Ler material completo
2. Identificar mensagem principal
3. Catalogar dados
4. Mapear argumentos

### Fase 2: Estruturação (15%)
1. Aplicar Pyramid Principle
2. Mapear SCQA
3. Definir sequência de slides
4. Validar MECE

### Fase 3: Design (30%)
1. Classificar tipo de cada slide
2. Definir layouts
3. Selecionar elementos visuais
4. Estabelecer hierarquia

### Fase 4: Especificação (30%)
1. Detalhar CADA slide (2000 palavras cada)
2. Incluir todos os 10 componentes
3. Prompts de IA completos
4. Fontes rastreáveis

### Fase 5: QA (4%)
1. Checklist macro (narrativa, MECE, flow)
2. Checklist micro (por slide)
3. Teste de 2 minutos (títulos contam história)

### Fase 6: Documentação (1%)
1. Arquivo principal de especificações
2. Design system
3. Bibliografia
4. AI prompts library

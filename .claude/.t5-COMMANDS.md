## 🔄 WORKFLOW PADRÃO

### Copy Workflow (Copying Elite)
```
1. @copy-chief
2. *diagnose {projeto}
3. Get recomendação de copywriter
4. @{copywriter-recomendado}
5. *sales-page / *email-sequence / *vsl-script
6. @joe-sugarman
7. *validate-triggers (30 pontos)
```

### Research Workflow
```
1. @t5-squad-research
2. *perform-market-research {tema}
3. Get relatório + matriz
4. *brainstorm {insights}
5. Get ideação estruturada
```

### Design Workflow
```
1. @t5-design-chief
2. *audit-codebase
3. *extract-tokens
4. Get tokens.json + pattern-library
5. *accessibility-check (WCAG 2.1 AA)
```

### SOP Workflow
```
1. @t5-squad-sop
2. *extract {processo}
3. Get SOP draft
4. *validate (14-point Crosby)
5. *publish
```

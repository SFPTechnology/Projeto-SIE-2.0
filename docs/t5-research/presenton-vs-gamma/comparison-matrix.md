# Presenton vs Gamma — Comparison Matrix

Data: 2026-05-17

## Matriz

| Dimensão | Presenton | Gamma | Paridade | Delta |
|---|---|---|---:|---|
| Criação por IA | Prompt/documento para PPTX/PDF; depende do modelo configurado. | Prompt, outline, docs e cards com UX polida. | 4/5 | Gamma tem melhor produto final; Presenton tem mais controle. |
| Qualidade visual pronta | Boa com templates; exige curadoria. | Muito forte para usuário não técnico. | 3/5 | Vantagem Gamma. |
| Exportação | PPTX/PDF via app/API. | PDF, PNG, PPTX e caminho para Google Slides. | 4/5 | Gamma tem mais formatos; Presenton é mais controlável. |
| Importação | Prompts e documentos; AI template generation a partir de PowerPoint. | PDF, PPTX, Google Docs, Google Slides, Word, URL, Notion conforme help center. | 3/5 | Vantagem Gamma em variedade. |
| Privacidade | Self-hosted, desktop, Ollama/local. | Cloud SaaS. | 1/5 | Vantagem decisiva Presenton. |
| Customização visual | HTML + Tailwind templates. | Temas, branding e fontes em planos superiores. | 4/5 | Presenton vence para customização técnica; Gamma vence para usuário final. |
| API/automação | API própria e MCP server; self-hostable. | API pública, MCP, Zapier, Make, n8n; API key a partir de Pro/Ultra/Teams/Business. | 4/5 | Gamma tem ecossistema SaaS; Presenton tem controle infra. |
| Custo | Open-source; custo é infra + modelo/API. | Free/Plus/Pro/Ultra/Teams/Business, créditos e limites. | 3/5 | Presenton vence em controle de custo; Gamma vence em conveniência. |
| Escala empresarial | Self-hosting dá controle, mas exige operação. | Times, business, API, conectores e billing SaaS. | 3/5 | Gamma vence se a empresa aceita SaaS. |
| Lock-in | Baixo. | Alto/médio: conteúdo e fluxo vivem no SaaS. | 2/5 | Vantagem Presenton. |

## Equivalência Geral

Paridade: `3/5 - equivalente parcial`

Eles resolvem o mesmo job principal, mas com filosofias opostas:

- Presenton: controle, privacidade, open-source, automação própria.
- Gamma: UX, velocidade, polimento, colaboração e distribuição SaaS.

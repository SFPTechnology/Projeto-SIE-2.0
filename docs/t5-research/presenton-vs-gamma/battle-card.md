# Battle Card — Presenton vs Gamma

## Veredito Rápido

- **Escolha Gamma** se você quer o melhor produto pronto para criar, editar, apresentar e compartilhar decks com mínima fricção.
- **Escolha Presenton** se privacidade, self-hosting, API própria, Ollama/local models e controle de templates são requisitos fortes.

## Onde Gamma Vence

- UX polida para usuário final.
- Criação, apresentação e compartilhamento no mesmo fluxo.
- Importação mais ampla.
- Integrações SaaS: API, MCP, Zapier, Make, n8n, ChatGPT, Claude.
- Mais forte para time comercial/marketing/consultoria que precisa entregar rápido.

## Onde Presenton Vence

- Open-source Apache-2.0.
- Docker/Desktop/self-hosting.
- Ollama e modelos locais.
- BYOK e OpenAI-compatible endpoints.
- Custom templates HTML/Tailwind.
- Menor lock-in e maior controle sobre dados.

## Objeção Comum

“Gamma é melhor, então por que olhar Presenton?”

Resposta: Gamma é melhor como SaaS pronto. Presenton é melhor como infraestrutura soberana. Se a restrição é privacidade, governança ou custo por escala, Gamma deixa de ser comparável diretamente.

## Decisão

Para SINKRA: benchmarkar os dois com o mesmo briefing. Usar Gamma como referência de UX e Presenton como candidato local-first.

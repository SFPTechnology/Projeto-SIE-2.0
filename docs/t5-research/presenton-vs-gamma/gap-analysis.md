# Presenton vs Gamma — Gap Analysis

## Gaps do Presenton Frente ao Gamma

| Gap | Prioridade | Evidência | Absorption |
|---|---|---|---|
| UX de criação e edição menos provada para usuário não técnico | P0 | Gamma posiciona criação, apresentação e compartilhamento como fluxo nativo. | Alta |
| Distribuição e colaboração via link/web menos madura | P1 | Gamma tem share links, presentation mode e analytics. | Média |
| Variedade de importação menor | P1 | Gamma help center lista importação de PowerPoint, Google Docs, Google Slides, Word, webpage URL e Notion. | Média |
| Branding/analytics/team workflow menos SaaS-ready | P1 | Gamma Pro inclui branding/fontes, analytics e sharing avançado. | Média |

## Gaps do Gamma Frente ao Presenton

| Gap | Prioridade | Evidência | Absorption |
|---|---|---|---|
| Sem self-hosting | P0 | Gamma é SaaS; Presenton roda Docker/Desktop/local. | Baixa para Gamma |
| Sem Ollama/local-first | P0 | Presenton documenta Ollama e modelos locais. | Baixa para Gamma |
| Menor controle de infraestrutura e dados | P0 | Presenton enfatiza controle total de modelos/dados. | Baixa |
| Lock-in comercial e crédito por uso | P1 | API Gamma opera com planos e créditos. | Média |

## Roadmap Recomendado

Se o objetivo é **uso imediato**, use Gamma.

Se o objetivo é **governança SINKRA/local-first**, use Presenton como baseline técnico e avalie gaps de UX.

Se o objetivo é **produto interno**, absorva do Gamma os padrões de UX: importação variada, editor card-based, links compartilháveis, analytics e templates guiados.

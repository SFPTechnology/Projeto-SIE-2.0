## AIOX Gaps (Absorption Candidates)

### P0 — Must-Have

| ID | Feature | Severity | Absorption | Effort |
|----|---------|----------|------------|--------|
| GAP-A01 | **Browser Daemon + Ref System** | HIGH | ADAPT infra-ops | L (13 pts) |
| GAP-A02 | **Canary Monitoring** | HIGH | ADAPT verify-deploy | M (5 pts) |

**GAP-A01: Browser Daemon**
gstack's `browse/src/` (13,192 LOC) implements a persistent Chromium daemon with:
- HTTP server on localhost (~100ms per command vs 2-3s per Playwright invocation)
- Ref system (@e1, @e2) — accessibility tree → stable element references
- Ring buffer logging (50K entries, O(1) push, async disk flush)
- Tab management, cookie handling, persistent state across commands

AIOX current: Per-invocation Playwright in `project-playwright` and `clickup-playwright` skills. Each command pays full startup cost.

**GAP-A02: Canary Monitoring**
gstack `/canary` watches for N minutes after deploy: console errors, perf regression, page failures. AIOX `verify-deploy` runs once and exits.

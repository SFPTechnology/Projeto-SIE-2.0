# Battle Card — Chatwoot vs Zendesk

**Data:** 2026-05-06 | **Bench:** chatwoot-vs-zendesk | **Score final:** Empate tecnico (78.85 vs 79.05)

---

## One-liner

| Player | Posicionamento |
|--------|---------------|
| **Chatwoot** | OSS MIT lider — flexibilidade categorical (self-host) + pricing transparente (1.0-1.2x sticker) |
| **Zendesk** | SaaS Enterprise lider global — compliance comprehensive + marketplace 1.977 apps + scale |

---

## Quando escolher Chatwoot

✓ PME / e-commerce com 2-20 agents | ✓ Time tecnico DevOps capaz de operar self-host
✓ Budget restritivo / TCO previsivel obrigatorio | ✓ Data sovereignty / OSS-first procurement
✓ WhatsApp BYOC (BR teams com BSP local) | ✓ Source code modifiability requirement

## Quando escolher Zendesk

✓ Healthcare / finance / gov com HIPAA / FedRAMP / ISO obrigatorios | ✓ Enterprise 50+ agents
✓ Multi-region GDPR strict (Dublin DC) | ✓ Voice/Talk + chat first-class hybrid ops
✓ Marketplace 2k apps plug-and-play | ✓ Apple Business Chat retail premium

## Switching dynamics

- **Off Zendesk → Chatwoot:** crescente. Hiver/Featurebase/Helpjuice mostram switching market ativo. Razao primaria: cost escalation 2-3x, complexity, AI fragmentation.
- **Off Chatwoot → Zendesk:** quando OSS team falha em escalar self-host ops, OU quando compliance audit obriga.

## Tensao aberta para o bench-score 3-way

Octadesk (par 3) ocupa o "meio" da curva pricing (R$79+) com BR-fit superior. **Pergunta para o 3-way:** Chatwoot (OSS flex) + Zendesk (enterprise compliance) + Octadesk (BR-PME) podem ser **set complementar** mais que substituto?

# 90-Day Launch Plan — Pre-launch (Semanas -8 a 0) + Semanas 1–12

**Data:** 2026-05-06
**Início real estimado:** 2026-05-13 (semana 0 = launch).
**Data de launch público alvo:** 2026-09-01 (semana 0 + 16 semanas de desenvolvimento + 8 de pre-launch).
**Premissa:** equipe nuclear de Alan + 1 senior engineer + 1 community/marketing manager + 1 designer. Crescimento conforme tração.

> **Observação:** este plano assume produto MVP funcionando em web no D-1 (semana 0). Se MVP não estiver pronto, semanas devem ser deslocadas. Não comece pre-launch sem produto testável.

## Riscos e gatilhos de pivot

| Trigger | Pivot |
|---------|-------|
| Mês 1 free→paid <5% | Refazer onboarding + simplificar hero copy |
| Mês 1 ARPU <R$30 | Reavaliar tier Solo R$29 — possivelmente unify Solo+Creator |
| Mês 2 churn pago >10% | Pause growth spend, foco em retention (NPS interviews + product fixes) |
| Mês 3 MRR <R$100k | Reavaliar GTM (talvez ICP-1 não converte como esperado; pivot para ICP-3 educator) |
| Mês 3 incumbente lança feature LATAM | Acelerar mobile + community moat (gaps mais defensáveis) |
| Mês 3 produto crash em escala | Halt growth, refactor backend, re-launch quando estável |

## Alternativas relevantes consideradas

| Alternativa | Razão |
| --- | --- |
| Microsoft PowerPoint + Copilot | Melhor compatibilidade PPTX e governança Microsoft; AI ainda menos 'one prompt to beautiful deck' que Gamma. |
| Google Slides + Gemini | Colaboração excelente e custo marginal baixo para Workspace; geração de decks completos ainda menos madura. |
| Prezi AI | Boa alternativa para storytelling não-linear e apresentações visuais; menos padrão para decks de growth/investor. |
| MagicSlides | Alternativa de baixo custo para Google Slides, próxima a SlidesAI. |
| Napkin AI | Excelente para diagramas/visuais, não substitui ferramenta completa de deck. |
| Figma Slides/Slidesgo/Adobe Express | Úteis para design e templates, mas não foram priorizados por menor fit AI-deck completo no briefing. |

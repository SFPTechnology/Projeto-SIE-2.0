# Deep Repo Notes

## `ppt-master`

Absorver:

- SVG como formato intermediário visual.
- Conversão para DrawingML/PPTX nativo.
- Template replication a partir de `.pptx`.
- Live preview e annotations.
- Animações/transições OOXML.
- Narração/TTS embutida no PPTX.
- Regras de compatibilidade SVG/PPTX.

Não absorver diretamente:

- Estrutura de skill inteira sem adaptação SINKRA.
- Dependência implícita de modelo específico como requisito operacional.

## `banana-slides`

Absorver:

- UX de criação por ideia/outline/page description.
- Edição verbal de região/slide.
- Asset toolbox.
- Vídeo com narração.
- Fluxo de material parsing.

Cuidado:

- Licença AGPL-3.0.
- Forte dependência de modelos/imagens específicos.
- Editable PPTX ainda tratado como beta/in progress em partes do README.

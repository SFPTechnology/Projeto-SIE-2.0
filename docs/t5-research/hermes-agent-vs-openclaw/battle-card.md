## Key Differentiators

### Hermes Wins

| Feature | Why It Matters |
|---------|---------------|
| **Self-improving loop** | Creates skills from experience, improves them during use |
| **Memory sophistication** | Honcho user modeling, self-nudging, FTS5 cross-session |
| **6 execution backends** | SSH, Modal, Daytona, Singularity = "not tied to your laptop" |
| **RL training pipeline** | Batch runner + Atropos = training data from agent behavior |
| **Anti-detection browser** | Camofox stealth browsing with VNC debugging |
| **Migration from OC** | `hermes claw migrate` imports OpenClaw data |

### OpenClaw Wins

| Feature | Why It Matters |
|---------|---------------|
| **Native apps** | macOS, iOS, Android — 700+ Swift/Kotlin files |
| **93 extensions** | 35 providers, 23 channels, 24 tools — proven plugin model |
| **1,584 contributors** | 7.8x community, corporate sponsors |
| **3,534 test files** | 70% coverage, E2E, drift detection |
| **23+ channels** | iMessage, Teams, LINE, Twitch, Nostr, Voice Call |
| **Plugin SDK** | Typed contracts, import boundaries, manifest lifecycle |

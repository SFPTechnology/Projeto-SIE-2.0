# QA-03 — Integração, dados, segurança e UX

Veredito: **APROVADO** para integração e interface de estudo implementadas; liberação normativa integral bloqueada no QA-02.
Perspectiva do assistente principal; não auditor independente humano.

- ALTA, aberta — propagação automática até os motores de dimensionamento não implementada. API entrega estudo, sem sobrescrever corrente canônica; uso automático vedado no contrato.
- MÉDIA, corrigida — edição do JSON poderia deixar memória antiga exportável. Eventos de entrada limpam memória; resposta de requisição antiga é descartada se documento mudou. Exportação exige resultado atual.
- MÉDIA, corrigida — textos de usuário/regra não entram por innerHTML; tabela e memória usam textContent. API recusa fontes em branco e campos extras pelos contratos tipados.
- MÉDIA, controlada — endpoints locais autenticados pelo mecanismo existente; histórico usa concorrência otimista e UUID imutável. API de cálculo é stateless e sem escrita.

Testes de referência: API cálculo, autenticação ausente, conflito de revisão, topologia divergente, histórico stale por alteração de levantamento/carga, comparação de equipamentos e tentativa de status VERIFIED. Navegador real: 26 cenários passaram em 45,18 s; inclui F06, edição que invalida memória, bloqueio de exportação stale, regra VERIFIED recusada e tela móvel de 390 px sem overflow. Chromium 153 temporário com GPU/GL desativados; o download padrão Playwright estava truncado. Não houve alteração no navegador do usuário.

# Conexão local e configurações
Instalar dependências conforme pyproject.toml do projeto. Definir SIE_ENV=dev (test nos ensaios), SIE_LOCAL_DB_PATH em diretório privado e SIE_LOCAL_API_TOKEN aleatório com pelo menos 24 caracteres. Nunca versionar valores. Executar uvicorn sie_api.main:app --host 127.0.0.1. Não usar proxy público para a API local. Token é enviado em Authorization Bearer; nenhum token em HTML, URL ou relatório. Usar caminhos diferentes DEV/TEST e não apontar para dados reais.
Rotas existentes PUT/GET /api/v1/local/projetos preservadas, criação revisão esperada zero, atualização revisão atual; conflito 409 exige recarregar/conciliar. API do snapshot canônico mantém contratos F02. Novo arquivamento é somente método administrativo interno; não exposto como botão destrutivo. Não houve mudança de interface.
Produção: SIE_ENV=prod bloqueia o armazenamento local mesmo com token. Não existe provisionamento PostgreSQL, segredo real, deploy ou migração de produção neste incremento.

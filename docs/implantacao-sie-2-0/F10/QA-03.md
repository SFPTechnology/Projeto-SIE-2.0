### Inspeção estática

API usa autenticação local `_storage`, UUIDs e registry para resolver caminhos no servidor. Downloads usam attachment/octet-stream, nosniff e CSP sandbox; preview iframe não permite scripts; permite mesma origem e modal para impressão do documento isolado. O token fica em campo de senha/memória, não é persistido no armazenamento do navegador. Fonte SVG aceita somente subset geométrico e rejeita DTD, entidades, script, eventos, URL e recursos externos.

Limites: token global é single-owner local e não ACL multiusuário. Banco e filesystem privados constituem autoridade; hashes não são assinatura e não impedem adulteração por ator com escrita arbitrária em ambos. Verificar-ler download tem limite diante de escritor externo malicioso, fora do protocolo cooperativo documentado.

🎯 COMO USAR
═══════════════════════════════════════════════════════════════════════════════

Opção 1: Usar arquivo HTML pronto
  └─ Abra: docs/TUTORIAL-NBR5410-Quantidade-TUG-Iluminacao.html
  └─ Imprima: Ctrl+P → "Salvar como PDF"

Opção 2: Converter via PowerShell (recomendado)
  └─ cd docs/
  └─ .\exemplos\converter-md-para-html-pdf.ps1 `
       -InputFile "TUTORIAL-NBR5410-Quantidade-TUG-Iluminacao.md" `
       -GeneratePDF

Opção 3: Converter com Pandoc
  └─ pandoc TUTORIAL-NBR5410-Quantidade-TUG-Iluminacao.md \
       -o TUTORIAL-NBR5410-Quantidade-TUG-Iluminacao.html

Opção 4: Automatizar em CI/CD (GitHub Actions)
  └─ Veja seção 12.8 do tutorial para exemplo

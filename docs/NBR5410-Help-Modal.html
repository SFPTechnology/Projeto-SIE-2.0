📋 Guia de Ajuda — Conformidade NBR 5410

Validação de segurança elétrica em banheiros conforme NBR 5410:2004

O que é este formulário?

Este formulário implementa os requisitos técnicos da NBR 5410:2004 — Instalações Elétricas de Baixa Tensão em Edificações. É um instrumento de validação de conformidade para circuitos e equipamentos em ambientes de banheiro, que possuem requisitos de proteção rigorosos.

ℹ️
A NBR 5410 é a norma brasileira que estabelece as exigências essenciais de segurança para instalações elétricas. Cumprir seus requisitos em banheiros é CRÍTICO para prevenir acidentes elétricos.

Zona 1-2 SEMPRE precisa de DB

📝 Descrição dos 6 Campos

1️⃣ Zona do Banheiro OBRIGATÓRIO
Define a localização do equipamento em relação à banheira. Diferentes zonas exigem diferentes níveis de proteção.
Zona Localização Distância da Banheira IP Mínimo
Zona 0 Interior da banheira 0m (dentro) IPX7/X8
Zona 1 Ao redor da banheira 0 a 0,6m IPX4
Zona 2 Próximo à banheira 0,6m a 1,2m IPX4
Zona 3 Fora do banheiro >1,2m IPX1
📌 Exemplos:
Tomada a 0,3m do espelho → Zona 1
Tomada a 0,8m da banheira → Zona 2
Ventilador a 2m de distância → Zona 3
2️⃣ DB Informado OBRIGATÓRIO
Indica se há proteção por Disjuntor Residual (DR/DDR) no projeto. É o componente de proteção contra choques elétricos mais importante.
Opções:
  • ✅ SIM Circuito protegido por DR — Projeto seguro
  • ❌ NÃO Circuito sem proteção — NÃO-CONFORME (crítico!)
⚠️
Crítico: Se a zona é 1 ou 2 e o DB é "Não", o projeto está NÃO-CONFORME com NBR 5410. DR é obrigatório.
3️⃣ Grau de Proteção IP OBRIGATÓRIO
Código de proteção do equipamento contra contato com partes vivas e ingresso de água. Formato: IPXY (exemplo: IP44, IPX7).

📊 Tabela de Proteção (Y — Água)

Código Proteção Quando Usar
IPX1 Gotejamento Zona 3 (áreas secas)
IPX4 Jatos de água Zona 1-2 (padrão)
IPX5 Jatos potentes Áreas externas
IPX7 Submersão temporária Zona 0 (raro)
✅ Exemplos Válidos:
IP44 — Padrão para banheiro (Zona 1-2)
IP54 — Proteção extra
IPX7 — Submersível
❌ Exemplos Inválidos:
IP20 — Inadequado em banheiro
IP 44 — Não escrever com espaço
IP00 — Não permitido
4️⃣ Influência Externa OPCIONAL
Indica se há fatores ambientais adicionais (temperatura extrema, sauna, umidade muito alta, etc.).
Opções:
  • OBRIGATÓRIO Há fatores especiais (ex: sauna, ambiente muito úmido)
  • OPCIONAL Banheiro comum, sem fatores adicionais (padrão)
  • NÃO APLICÁVEL Circuito em área seca ou sem relevância
5️⃣ Classe OBRIGATÓRIO
Classificação técnica do equipamento. Exemplos: AD2 (tomada), AL2 (iluminação), MD1 (motor/ventilador).

📌 Códigos Comuns para Banheiro:

Código Equipamento Proteção IP Mín.
AD2 Tomada em banheiro Reforçada IP44
AL2 Iluminação LED/fluorescente Reforçada IP44
MD1 Ventilador/exaustor Simples IP44
AD4 Proteção máxima Máxima IP65
⚠️
Nunca use AD1 em banheiro. Classe 1 é apenas para áreas secas.
6️⃣ Observações OPCIONAL
Campo para notas técnicas que justificam a conformidade ou documentam particularidades.
✅ Exemplos Bons:
"Tomada Legrand, classe AD2, IP44, protegida por DR 30mA, Zona 2"
"Luminária LED anti-embaçamento, IP67, adequada para Zona 1"
"Ventilador Intelbras com sensor automático, DR independente 30mA"

❓ Dúvidas Frequentes

P: Qual é a diferença entre IP44 e IPX4? ▼

IP44: Proteção contra contato (até 1mm) + Jatos de água

IPX4: Sem proteção contra contato + Jatos de água

Conclusão: Em banheiros, IP44 é preferível pois oferece ambas as proteções.

P: Posso usar tomada IP20 em banheiro se tiver DR? ▼

Não. O DR protege contra choques elétricos, mas não contra água. Uma tomada IP20 deixa partes vivas expostas à umidade, causando corrosão e risco de curto-circuito.

Conclusão: IP44 é obrigatório em Zona 1-2, independentemente do DR.

P: É necessário DR em Zona 3? ▼

Tecnicamente não é obrigatório (Zona 3 está fora do banheiro), mas é altamente recomendado.

Se a mesma DR alimenta Zona 1-2, qualquer circuito associado herda a proteção, o que é uma boa prática.

P: O que fazer se o equipamento não tem IP especificado? ▼

Não use. Equipamentos sem certificação ou especificação de IP não devem ser instalados em banheiros.

Solicite ao fornecedor a documentação técnica ou procure uma alternativa certificada.

P: Posso usar classe AD1 em banheiro? ▼

Não. Classe AD1 é apenas para áreas secas (IP20).

Classe AD2 é o mínimo para banheiros (Zona 2-3).
Classe AD4 é melhor para Zona 1.

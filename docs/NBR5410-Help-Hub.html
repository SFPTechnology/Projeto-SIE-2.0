🔧 Como Integrar — Guia Técnico

Integração no Formulário HTML

Adicione um botão de ajuda próximo a cada campo:

<!-- Botão de ajuda genérico --> <div class="form-group"> <label for="zona"> Zona do Banheiro <button onclick="showHelp()">❓</button> </label> <select id="zona">...</select> </div> <!-- Modal de ajuda --> <div id="helpModal" style="display:none;"> <iframe src="NBR5410-Help-Modal.html" style="width:100%; height:100%; border:none;"> </iframe> </div> <script> function showHelp() { window.open('NBR5410-Help-Modal.html', 'help', 'width=1000,height=800'); } </script>

💡 Dica: Use iframes ou modais bootstrap para integração mais elegante

Integração JavaScript (Dinâmica)

Carregue descrições do JSON dinamicamente:

// Carregar schema fetch('NBR5410-Help-Schema.json') .then(res => res.json()) .then(data => { const campos = data.conformidade_nbr5410.campos; // Popover ao focar document.getElementById('zona') .addEventListener('focus', () => { showTooltip('zona', campos.zona_do_banheiro.descricao_curta); }); }); // Validação com regras críticas function validarCampo(fieldName, value) { const bloqueadores = data .conformidade_nbr5410.bloqueadores_criticos; bloqueadores.forEach(bloq => { if (bloq.condicao.includes(fieldName)) { console.warn('ALERTA:', bloq.severidade); } }); }

Integração em API REST

Servir help descriptions em endpoints:

// Node.js / Express const helpSchema = require('./docs/NBR5410-Help-Schema.json'); app.get('/api/help/campo/:fieldName', (req, res) => { const field = helpSchema .conformidade_nbr5410 .campos[req.params.fieldName]; if (field) { res.json({ descricao: field.descricao_longa, opcoes: field.opcoes, exemplos: field.exemplos }); } }); // Cliente (React/Vue) async function obterAjuda(campoNome) { const response = await fetch( `/api/help/campo/${campoNome}`); const help = await response.json(); mostrarTooltip(help); }
